# PDF 安全遮盖台

一款**纯前端、无需上传文件**的 PDF 遮盖（涂黑）工具。所有解析、编辑、导出均在浏览器本机完成，PDF 不会离开你的电脑。

## 功能

- 导入本地 PDF（文件选择或拖拽入窗口），逐页渲染预览
- 在页面上**绘制、移动、缩放**遮盖框；遮盖框以 PDF 页面坐标保存，缩放、旋转视图、切换页面后位置不漂移
- **文本查找遮盖**：输入换行分隔的词或短语，浏览器本地逐页提取文字并定位命中，逐项勾选或全选后一次加入遮盖
- 左侧页面列表显示缩略图与每页遮盖数量，点击快速跳转
- **撤销 / 重做**（Ctrl+Z / Ctrl+Shift+Z 或 Ctrl+Y），Delete 键删除选中框
- 安全导出：每页按 **144 DPI** 栅格化，遮盖区域烧入**纯黑**，生成全新 PDF——
  不保留被遮区域的可复制文字，也不保留任何原始页面对象，且各页尺寸与原页一致

## 技术栈

React 18 · TypeScript · Vite · pdfjs-dist（渲染）· pdf-lib（生成 PDF）· Nginx（静态托管）

## 快速开始（Docker，一条命令）

```bash
docker compose up --build
```

启动后访问：**http://localhost:8080**

> 如需更换端口，修改 `docker-compose.yml` 中的 `ports`，如 `"9000:80"`。

## 本地开发

```bash
npm install
npm run dev      # 访问 http://localhost:5173
```

生产构建：`npm run build`，产物在 `dist/`。

## 操作方法

1. **导入**：点击「导入 PDF」或把 PDF 文件拖入窗口。
2. **绘制遮盖**：默认处于「绘制遮盖」模式，在页面上按住鼠标拖出矩形即可。
3. **调整**：切换到「选择 / 调整」模式后，点击选中遮盖框，拖动移动位置，拖动四角/四边手柄缩放；按 Delete 删除选中框，「清空本页」可一次删除当前页全部遮盖。
4. **文本查找遮盖**：
   1. 点击工具栏「文本查找遮盖」打开右侧面板；
   2. 在输入框中填入要查找的词或短语，**每行一个**（空行会被忽略，重复行只查找一次）；
   3. 点击「查找」，工具在浏览器本地逐页提取文字并扫描，面板显示「第 x / n 页」进度，可随时「取消」（取消后保留已扫描页面的结果）；
   4. 命中结果按页列出，并在当前查看页用黄色框高亮，鼠标悬停列表项可在画布上强调显示，点击命中文字可跳转到对应页面并定位；
   5. 用每项前的勾选框逐项选择，或用页首 / 顶部的复选框整页、全选；
   6. 点击「加入遮盖」，所有勾选项**一次性**加入遮盖（整批操作只产生一条撤销记录，可 Ctrl+Z 整体撤回）。

   查找规则与状态提示：
   - 搜索仅在**单页内**进行，不会跨页拼接；查询词和页面文本中的连续空白（空格、制表符、换行）统一按一个空格匹配；
   - 匹配可跨越相邻的 pdf.js 文本片段；一个命中只按实际命中的字形范围生成一个或多个框（跨行时每一行一个框），**不会遮住同一行中未命中的间隔文字**；
   - 与已有遮盖坐标相同的候选标记为「已遮盖」并自动跳过，重复搜索或重复应用不会产生重复框；删除或撤销遮盖后，对应候选可重新勾选；
   - 空查询、全文无结果、以及没有文字层的页面（如纯扫描件）都会给出明确提示；
   - 全部文字提取与匹配均在本机完成，不上传任何内容。
5. **视图**：工具栏可缩放（50%–300%）、旋转视图（仅影响查看，不影响导出结果）、翻页。
6. **撤销 / 重做**：工具栏按钮或快捷键。
7. **导出**：点击「导出安全 PDF」，逐页栅格化并烧入遮盖后，自动下载 `原文件名_已遮盖.pdf`。

## 安全说明

- 源文件通过 `FileReader` 读入浏览器内存，全程无网络请求，不上传任何数据；文本查找的文字提取与匹配同样在浏览器本地完成。
- 导出的 PDF 每页只是一张 144 DPI 的位图：原文字层、矢量图形、注释、元数据均不会进入新文件，被遮盖的内容无法通过复制、搜索或删除遮盖层恢复。

> 提示：文本查找依赖 PDF 自带的文字层。纯图片扫描件无法直接文本查找，需先经 OCR 生成可提取文字后再使用。
